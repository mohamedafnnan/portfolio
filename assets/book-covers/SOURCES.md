# Book cover image sources

Covers are local thumbnails for this personal portfolio shelf. Covers are shown as book-identification artwork, not represented as original work.

Most cover files are downloaded from the Open Library Covers API and selected from title-matched Open Library catalog records. Catalog search: https://openlibrary.org/search ; cover service documentation: https://openlibrary.org/dev/docs/api/covers
