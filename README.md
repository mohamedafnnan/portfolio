# Afnnan Portfolio

A self-contained personal portfolio website exported from the latest Afnnan Engineering HTML bundle.

## Structure

- `index.html` — the complete site, including its styles, scripts, fonts, media, and interactive 3D experience.

No build step or external asset directory is required. The file can be opened directly in a browser or served by any static web host.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
